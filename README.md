# Núcleo — Banco de Dados · Semestre 2

Portal colaborativo de estudos para as disciplinas do segundo semestre da graduação em Banco de Dados.

Inclui trilhas semanais, explicações em diferentes perspectivas, laboratórios interativos, exercícios comentados e simulados dinâmicos.

O progresso e o histórico dos simulados são armazenados somente no navegador de cada aluno.
